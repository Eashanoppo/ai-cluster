# 18. Frontend Specification

## 18.1 Purpose

The **Frontend** is the **User Experience and Visualization Layer** of the AI Cloud Operating System (AIOS).

It provides a modern, responsive, real-time interface that allows users, administrators, operators, and hackathon judges to interact with the platform without needing knowledge of Kubernetes, Ray, or GPU infrastructure.

The frontend enables users to configure simulation scenarios, launch AI workloads, observe autonomous cluster behavior, monitor infrastructure health, and understand every decision made by **processors.py**.

The frontend does **not** contain business logic or scheduling intelligence. All autonomous decisions remain within the backend AI Control Plane.

# 18.29 Functional Requirements

The frontend shall:

* Be implemented using **Next.js 16.1.2**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**.
* Provide a responsive, enterprise-grade user interface for interacting with AIOS.
* Support real-time monitoring through WebSockets.
* Visualize infrastructure, workloads, predictions, anomalies, costs, energy usage, and AI decisions.
* Include an interactive Simulator Engine for configuring companies, users, workloads, SLAs, and scenarios.
* Present an explainable AI Decision Center showing why processors.py performed each action.
* Use Zustand for client state management and TanStack Query for server state synchronization.
* Communicate exclusively with the Django REST API and WebSocket endpoints.
* Maintain a strict separation between presentation logic and business logic, ensuring that all autonomous scheduling, optimization, migration, scaling, and recovery operations remain within the backend AI Control Plane (`processors.py`).
